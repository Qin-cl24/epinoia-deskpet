`pet.html` 里 `.fx-*` 的 left/top 就是各层在这个画布里的位置）。

## ✅ 导出时请务必这样（踩过坑）

1. **所有层同一个画布尺寸（543 × 626）**，不要各自裁边。
   → 只要尺寸和原来一样，坐标我一个都不用改；如果画布尺寸变了，告诉我，我按比例重算全部坐标。
2. **PNG，透明底，不要白边/底板**（现在的图已经去过白边了，保持就好）。
3. **被挡住的部分也要画出来**（这点最关键）。比如耳根藏在头发底下那截、裤腰被上衣压住的边，
   在源文件里是完整的；导出时别按可见区域裁掉，否则一转动就露背景。
4. 文件名用英文小写 + 连字符，一只一层的按 `-L` / `-R` 分（左 = 画面左边那只）。

## 🧭 一条总原则：只拆「会单独动」的东西

拆层不是越多越好——每多一层就是一个 PNG + 一个 DOM 节点，狐狐已经有 21 层了，
桌宠是悬在桌面上的小窗，层数越多合成越费、遮挡顺序也越容易出错。
判断标准很简单：**我们会不会让它单独动？**

| 部件 | 要不要拆 | 理由 |
| --- | --- | --- |
| 白衬衫领口 / 黑外套（现在同在 `top.png`） | ❌ 不用 | 白衬衫只露领口一小块（`top.png` 里近白像素 966 个，占 7%），跟外套一起动看不出差别；现在也没有「单独翻领口」的动作 |
| 裤子 / 腰带（`layer19`） | ❌ 不用 | 一起动 |
| 鞋 / 裤脚（`shoes`） | ❌ 不用 | 一起动 |
| 袖子 / 黑外套 | ❌ 不用 | 一起动；袖子已经能整层做手势 |
| **脖子 / 手（现在同在 `neck-hands.png`）** | ✅ **建议拆** | 待办里还有「骰子 720° 回手」「递手从眼睛下面穿过」这类动作，手要单独动就得和脖子分开，最好分左右手（`hand-L` / `hand-R`） |
| 眼睛那一套（瞳孔/眼白/高光/睫毛/眉毛） | ✅ 拆 | 眨眼要单独动，见上表 |
| 耳朵 / 尾巴 / 呆毛 / 刘海 / 后发 | ✅ 已经拆好 | 都在单独动 |

整只狐的整体动作（呼吸、跳一下、走路摇摆、扑）都是对 `.fox-inner` 整体做变换，
身体内部各层的相对位置不变 —— 所以身体部件只要「相对关系不变」，就不用拆。
