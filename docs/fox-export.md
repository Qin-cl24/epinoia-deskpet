# 狐狐形态：分层导出清单（给主人）

小狐狸是逐层 PNG 叠出来的（`.fox` 画布 **543 × 626**，所有层共用这一个坐标系，
`pet.html` 里 `.fx-*` 的 left/top 就是各层在这个画布里的位置）。
这份清单是 2026-10-23 ～ 10-24 调耳朵/眨眼踩出来的需求，下一次导出照着来就行。

## ✅ 导出时请务必这样（踩过坑）

1. **所有层同一个画布尺寸（543 × 626）**，不要各自裁边。
   → 只要尺寸和原来一样，坐标我一个都不用改；如果画布尺寸变了，告诉我，我按比例重算全部坐标。
2. **PNG，透明底，不要白边/底板**（现在的图已经去过白边了，保持就好）。
3. **被挡住的部分也要画出来**（这点最关键）。比如耳根藏在头发底下那截、裤腰被上衣压住的边，
   在源文件里是完整的；导出时别按可见区域裁掉，否则一转动就露背景。
4. 文件名用英文小写 + 连字符，一只一层的按 `-L` / `-R` 分（左 = 画面左边那只）。

## 🎯 这次最想要的多拆几层（都是这次被迫用脚本硬拆的）

| 想要的新层 | 为什么 | 现在的权宜做法 |
| --- | --- | --- |
| `eye-white-L/R`（眼白） | 眨眼时整只眼睛一起闭，眼白也要能跟着收起 | 没有，现在眼白在 head 里 |
| `pupil-L/R`（瞳孔/虹膜） | 原来瞳孔和深色眼珠烤在 `head.png` 里，压扁眼睛图层时底下眼珠不动，看起来「只有睫毛在动」 | `tools/fox-eye-pupil.py` 用亮度阈值把眼珠从 head 里抠出来，再给 head 补肤色（只差 3 像素，但仍是权宜） |
| `eye-highlight-L/R`（高光） | 高光跟不跟眼睛走，做法不一样，单独一层最好调 | 现在跟虹膜混在 `eyes.png` 里 |
| `lash-L/R`（上半睫毛线） | 眨眼时睫毛要停在眼皮位置 | 拆成 `eye-strokes.png`，靠脚本按连通域分组 |
| `brow-L/R`（眉毛） | 眨眼时眉毛**不该**跟着飞 | 同上，现在混在 strokes 里 |
| `eye-closed-L/R`（闭眼那根线，可选） | 有专门画的闭眼线，比把眼睛压扁好看得多 | 现在靠 `scaleY(.1)` 压出一条线 |
| `ear-root-L/R`（耳根补片，可选） | 左耳摆动时耳根会露背景缝 | `tools/fox-ear-patch.py` 从 ear-L 自己裁了块静止补片 + 摆动时反向平移 |
| `head`（干净的头部） | 上面那些拆出去之后，head 就只剩脸皮/头发，不再烤眼珠 | —— |
